  - MOP(Message oriented Programming)
  - 앨런 케이가 생각했던 객체지향의 핵심은 클래스, 상속과 달랐다.
    - **근거**: 객체지향과 밀접한 C++, JAVA의 핵심 아이디어가 클래스와 상속이기는 하지만, 클래스가 없는 JS도 객체 지향을 구현할 수 있다.
  - 객체 지향에서 중요한 것은 객체 하나하나가 아니라, 여러 객체가 서로 메시지를 주고받으며 '협력'해서 전체 기능을 완성하는 구조
  - 타입 계층(상속, 인터페이스)는 메시지 전송에 대한 약속들을 정의해 놓은 것
  - 이러한 객체들은 실제 세계의 개념이나 역할을 옮겨온다.
  - 앨런 케이
    - **메시징(message passing)**
    - **캡슐화(encapsulation)**
    - **동적 바인딩(dynamic binding)**
  ```python
  class Animal:
    def speak(self):
      raise NotImplementedError("서브클래스에서 구현하세요.")
  
  class Dog(Animal):
    def speak(self):
      return "멍멍!"
  
  class Cat(Animal):
    def speak(self):
      return "야옹!"
  
  def animal_sound(animal: Animal):
    # 메시지 전송: animal에게 speak() 요청
    print(animal.speak())
  
  dog = Dog()
  cat = Cat()
  
  animal_sound(dog)  # 멍멍!
  animal_sound(cat)  # 야옹!
  ```
