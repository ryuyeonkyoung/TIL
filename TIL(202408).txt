백트래킹
static void combination(int[] arr, boolean[] visited, int start, int n, int r) {
    if (r == 0) {
        print(arr, visited, n);
        return;
    }
    
    for (int i = start; i < n; i++) {
        visited[i] = true;                  // 현재 요소를 선택
        combination(arr, visited, i + 1, n, r - 1); // 다음 요소를 선택하기 위해 재귀 호출
        visited[i] = false;                 // 선택한 요소를 다시 방문하지 않도록 설정
    }
}

객체, 클래스, 인스턴스의 개념
"자바에서 객체는 클래스의 인스턴스입니다."
클래스: 필드와 메소드를 정의하는 구조
객체 : 클래스에서 정의한 필드와 메소드를 실제로 지니고 있는 인스턴스입니다
인스턴스: 객체와 같은 의미로 사용됨. 클래스의 구체적인 구현체.
(클래스로 객체를 만드는 과정을 인스턴스화라고 함)

지시자 include vs 액션태그 include
*지시자 include
