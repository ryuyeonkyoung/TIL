# 2장: 객체 생성과 파괴

### 아이템 1: 생성자 대신 정적 팩터리 메서드를 고려하라
**장점**
1. 이름을 가질 수 있다.
2. 호출될 때마다 인스턴스를 새로 생성하지 않아도 된다.
3. 반환 타입의 하위 객체를 반환할 수 있는 능력이 있다.
4. 입력 매개변수에 따라 매번 다른 클래스의 객체를 반환할 수 있다.
5. 정적 팩토리 메서드를 작성하는 시점에서는 반환할 객체의 클래스가 존재하지 않아도 된다.

**단점**
1. 상속을 하려면 public이나 protcted 생성자가 필요하니 정적 팩토리 메서드만 제공하면 하위 클래스를 만들 수 없다.
2. 정적 팩토리 메서드는 프로그래머가 찾기 어렵다.

### 자바의 불변 객체(Immutable)와 가변 객체(Mutable) 정리

#### 불변 객체 (Immutable Object)
- 한 번 생성되면 내부 상태(필드 값)가 절대 변경되지 않음
- 값 변경 시 항상 새로운 객체가 생성됨
- 스레드 안전(thread-safe)
- 예시:
    - String
    - Wrapper 클래스 (Integer, Long, Double, Boolean 등)
    - java.time 패키지의 날짜/시간 클래스 (LocalDate, LocalDateTime, Instant 등)
    - record (Java 16+)

#### 가변 객체 (Mutable Object)
- 생성 후에도 내부 상태(필드 값)를 변경할 수 있음
- 참조를 공유하면 외부에서 값이 변경될 수 있음
- 스레드 안전하지 않을 수 있음
- 예시:
    - 컬렉션(List, Set, Map 등)
    - 배열(Array)
    - StringBuilder, StringBuffer
    - 대부분의 사용자 정의 클래스(필드가 public이거나 setter가 있으면)

- 추상화는 저차원 상세 개념에서 고차원 일반 개념을 분리한다.
- 공통된 로직은 추상화해서 재사용하고, 차이는 구체적으로 분리하기
- 추상 클래스(기초 클래스): 고차원 개념
- 파생 클래스: 저차원 개념
